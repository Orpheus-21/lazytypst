# lazytypst

lazytypst is a terminal program for Typst documents.

## Status

The project is at the planning stage. No program code exists yet. The plan is in `tasks/plan.md`. The task list is in `tasks/todo.md`.

## What it will do

lazytypst will list the Typst projects in a folder. The user will open a `.typ` file, edit the file, and see a live preview of the compiled page. The program will run the `typst` command as a child process. The program will be written in Rust.
